# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.
Use one of these private channels:

- Send an email to **security@halv.ai**.
- Use GitHub private vulnerability reporting: open the **Security** tab of this repository and click **Report a vulnerability**.

Include these items in your report:

- The Halv version and the operating system.
- The steps that reproduce the problem.
- The effect that you saw, for example a data leak or code execution.

## What we do

1. We confirm that we received your report.
2. We examine the report and tell you our assessment.
3. We fix the problem and publish a release.
4. We give you credit in the release notes, if you agree.

## Disclosure

We ask for 90 days from your report to fix the problem before you disclose it.
If we publish a fix earlier, you can disclose it after the release.
If we need more time, we tell you why and agree on a new date with you.

## Scope

This policy covers these items:

- The Halv desktop app in this repository.
- The `crates/halv-remote` protocol crate.
- The Halv services at halv.ai, for example the account service and the phone relay.

The latest release gets security fixes. Older releases do not.

For more information about Halv, go to [halv.ai](https://halv.ai).
